# ICE TECH Group

A simple beginner-friendly frontend website for ICE TECH Group.

## Files

- `index.html` — main website
- `styles.css` — website design
- `script.js` — mobile menu and current year
- `README.md` — setup instructions

## Run locally

You can simply double-click `index.html` to open it in your browser.

For a better development experience, open the folder in VS Code and use the Live Server extension.

## Deploy on Render

This is a static website, so you do not need Node.js, a database, or a backend.

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Log in to Render.
4. Create a new **Static Site**.
5. Connect your GitHub repository.
6. Use these settings:
   - Build Command: leave empty
   - Publish Directory: `.`
7. Click **Create Static Site**.
8. Render will give you a public URL.

## Customize

Open `index.html` in VS Code and change the text, email, WhatsApp number, services, and projects.

The main ICE TECH colors can be changed in `styles.css`.
